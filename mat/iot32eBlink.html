2. Conceitos Importantes

Antes de darmos início em nossos projetos, é importante conhecer alguns conceitos que serão utilizados no decorrer do e-book.

Internet of Things (IoT)

Descreve objetos físicos incorporados a sensores, software e outras tecnologias com o objetivo de conectar e trocar dados com outros dispositivos e sistemas pela internet.

O que é o ESP-32?

É uma placa de desenvolvimento de código aberto que utiliza o chip ESP32. É muito semelhante ao Arduino Uno, visto que ambos são microcontroladores. A vantagem de se utilizar o ESP-32 é ele possuir Wi-Fi e Bluetooth nativos, sendo ideal para automação residencial. Possui pinos digitais e portas analógicas, permitindo inclusive programação via OTA (Over The Air) por Wi-Fi.

Sinais Digitais e Analógicos

  • Sinais Digitais: Possuem quantidade limitada de níveis (Alto ou Baixo), como lâmpadas, buzinas, ventiladores, chaves seletoras e botões.
  • Sinais Analógicos: Podem assumir infinitos valores em um intervalo de tempo, como sensores de temperatura, umidade, pressão e potenciômetros.

Tensão e Corrente Elétrica

A tensão elétrica (Diferença de Potencial, medida em Volts - V) é a força necessária para mover os elétrons e criar uma corrente elétrica. Pode ser Contínua (CC) ou Alternada (CA). A corrente elétrica (medida em Ampères - A) é o movimento ordenado de cargas elétricas. Relação regida pela Lei de Ohm: $U = R \times I$.

3. Composição e Pinagem do ESP-32

Conhecer a disposição dos pinos (pinout) do ESP-32 DevKit v1 é fundamental para evitar ligações incorretas e danos ao microcontrolador.

+-----------------------------------+ | ESP-32 | EN ---| [1] [1] |--- VP (GPIO36) SENSOR_VP -| [2] [2] |--- VN (GPIO39) SENSOR_VN -| [3] [3] |--- GPIO34 GPIO34 -| [4] [4] |--- GPIO35 GPIO35 -| [5] [5] |--- GPIO32 GPIO32 -| [6] [6] |--- GPIO33 GPIO33 -| [7] [7] |--- GPIO25 GPIO25 -| [8] [8] |--- GPIO26 GPIO26 -| [9] [9] |--- GPIO27 GPIO27 -| [10] [10] |--- GPIO14 GPIO14 -| [11] [11] |--- GPIO12 GPIO12 -| [12] [12] |--- GPIO13 GND -| [13] [13] |--- GND 3V3 -| [14] [14] |--- VIN (5V) +-----------------------------------+

Pinout Detalhado:

  • GND: Pinos de referência Zero Volt (Terra).
  • 3V3: Saída do regulador interno de $3,3V$ (Corrente máxima recomendada: $250mA$).
  • VIN: Entrada de alimentação externa ($5V$ a $9V$).
  • GPIO (General Purpose Input/Output): Pinos digitais para entrada e saída de sinais. Nota: GPIOs 34, 35, 36 (VP) e 39 (VN) são exclusivamente de entrada (Input only).
  • ADC (Analog to Digital Converter): Converte sinais analógicos externos ($0V$ a $3,3V$) em valores numéricos digitais de 12 bits ($0$ a $4095$).

4. Baixando a IDE do Arduino

Para programar a placa, utilizamos a IDE do Arduino:

  1. Acesse o site oficial do Arduino e clique em Software.
  2. Selecione o seu sistema operacional (ex: Windows Win 7 and newer).
  3. Clique em Just Download e execute o instalador clicando em I Agree, selecione os componentes e a pasta de destino até concluir.

5. Configurando o ESP-32 na IDE

  1. Abra a IDE do Arduino, clique em Arquivo e depois em Preferências.
  2. No campo URLs Adicionais para Gerenciadores de Placas, insira: https://dl.espressif.com/dl/package_esp32_index.json.
  3. Vá em Ferramentas > Placa > Gerenciador de Placas, pesquise por esp32 da Espressif Systems e clique em Instalar.
  4. Selecione a placa em Ferramentas > Placa > ESP32 Arduino > ESP32 Dev Module.

6. Conhecendo o Blynk

O Blynk é um aplicativo focado em projetos IoT para comunicação via celular com o ESP-32 por Wi-Fi ou Bluetooth.

  • Crie uma conta em blynk.cloud inserindo um e-mail válido.
  • Na IDE do Arduino, instale a biblioteca do Blynk (versão desenvolvida por Volodymyr Shymanskyy) indo em Sketch > Incluir Biblioteca > Gerenciar Bibliotecas.

7. Projeto 1: Sequencial de LEDs

Controlaremos três LEDs (Vermelho, Amarelo e Verde) utilizando o aplicativo Blynk via Wi-Fi.

  • LED Vermelho: Porta digital D32 (com resistor de 1kΩ). Pino Virtual: V0.
  • LED Amarelo: Porta digital D26 (com resistor de 1kΩ). Pino Virtual: V1.
  • LED Verde: Porta digital D13 (com resistor de 1kΩ). Pino Virtual: V2.
#define BLYNK_PRINT Serial
#define BLYNK_DEVICE_NAME "Prof Georgino Rodrigo IoT"
#define BLYNK_TEMPLATE_ID "SEU_TEMPLATE_ID"
#include <WiFi.h>
#include <WiFiClient.h>
#include <BlynkSimpleEsp32.h>

char auth[] = "SEU_TOKEN";
char ssid[] = "SUA_REDE";
char pass[] = "SUA_SENHA";

int LEDVermelho = 32;
int LEDAmarelo = 26;
int LEDVerde = 13;

BLYNK_WRITE(V0) {
  int valor = param.asInt();
  digitalWrite(LEDVermelho, valor);
}
BLYNK_WRITE(V1) {
  int valor = param.asInt();
  digitalWrite(LEDAmarelo, valor);
}
BLYNK_WRITE(V2) {
  int valor = param.asInt();
  digitalWrite(LEDVerde, valor);
}

void setup() {
  Serial.begin(115200);
  Blynk.begin(auth, ssid, pass);
  pinMode(LEDVermelho, OUTPUT);
  pinMode(LEDAmarelo, OUTPUT);
  pinMode(LEDVerde, OUTPUT);
}

void loop() {
  Blynk.run();
}

8. Projeto 2: Ligando Lâmpada e Ventilador (Módulo Relé)

Utiliza um Módulo Relé de 2 canais para acionar cargas de potência (lâmpada e ventilador).

9. Projeto 3: Monitoramento de Temperatura e Umidade (DHT11)

Monitora temperatura (0 a 50°C) e umidade (20 a 90%) com o sensor DHT11.

  • Pino 1 (DHT11): 3.3V
  • Pino 2 (DHT11): D2 (Dados)
  • Pino 4 (DHT11): GND
  • Pinos Virtuais Blynk: V0 (Umidade) e V6 (Temperatura).
#define BLYNK_PRINT Serial
#define BLYNK_TEMPLATE_ID "SEU_TEMPLATE_ID"
#define BLYNK_DEVICE_NAME "Prof Georgino Rodrigo IoT"
#include <WiFi.h>
#include <WiFiClient.h>
#include <BlynkSimpleEsp32.h>
#include <DHT.h>

char auth[] = "SEU_TOKEN";
char ssid[] = "SUA_REDE";
char pass[] = "SUA_SENHA";

#define DHTPIN 2
#define DHTTYPE DHT11
DHT dht(DHTPIN, DHTTYPE);
BlynkTimer timer;

void sendSensor() {
  float h = dht.readHumidity();
  float t = dht.readTemperature();
  if (isnan(h) || isnan(t)) return;
  Blynk.virtualWrite(V0, h);
  Blynk.virtualWrite(V6, t);
}

void setup() {
  Serial.begin(9600);
  Blynk.begin(auth, ssid, pass);
  dht.begin();
  timer.setInterval(1000L, sendSensor);
}

void loop() {
  Blynk.run();
  timer.run();
}
